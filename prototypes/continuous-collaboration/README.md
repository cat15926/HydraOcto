# Clowder 行为复刻评审原型 v5

日期：2026-11-02。v5 原型对应[0.5 历史指导](../../../Multi-Agent-Docs/archive/design/continuous-collaboration-implementation-report-v0.5.md)。当前实施规则已更新为[0.6 指导](../../../Multi-Agent-Docs/design/continuous-collaboration-implementation-report.md)和[85 项覆盖清单](../../../Multi-Agent-Docs/design/clowder-replication-coverage.md)。这是独立编写的离线原型，不使用 Clowder 的源码、Prompt 或品牌素材；行为参照固定提交 c238b40a。

双击 [prototype.html](prototype.html) 即可单文件离线运行。也可通过本地静态服务打开 index.html。源码由 app.js、settings.js、styles.css 和 index.html 组成，修改后执行 `python3 scripts/export-collaboration-prototype.py` 导出。

## 建议体验路径

1. 打开「成员与运行时」，新建成员、填写职责、选择 Codex / Claude Code / API、模型和跟随默认或指定账户。编辑已有成员不会改写进行中的运行快照。
2. 打开「账户与登录」，查看官方登录示意，再点「模拟登录完成」；或登记 API 连接元数据。原型不采集真实密钥。切换默认账户需要先预览受影响成员，再应用。
3. 在「项目与材料」输入演示项目目录，预览后应用。只保存目录文字，不读取文件系统。当前会话的后续执行使用新目录，既有执行保留原快照。
4. 回到「持续会话」，直接发送消息。可选 @成员；无需先建立任务或选择消息类型。`@林 @序` 本条发给两人，下一条「继续」落到最近点名中的首个可用成员。任务负责人不会覆盖这个路由。
5. 运行卡显示模拟执行。展开「Agent 事件模拟器」可注入无目标进展、定向 FYI、结构化协助、串行文本接力、多人征询、普通任务、审批和产物事件。这是代替模型回调的评审工具，不是用户发送前置表单。
6. 在「任务」查看责任版本、准备转交。先停止并确认任务所绑定的旧执行退出，再应用转交；不要求目标先接受。普通任务允许用户标记完成，或匹配责任版本和执行身份的模拟 Agent 回调完成。
7. 在「队列」观察忙成员排队、独立成员启动、调整顺序与精确追加对账。在「上下文」查看当前模拟执行实际绑定的消息；在「记录」查看独立于任务负责人和运行槽的球权投影。
8. 可以新建、切换、重命名、置顶、归档恢复会话，也可从一条消息建立分支。引用和文件附件元数据可随消息发送。

## 本版修订

| 原 v4 设计 | v5 默认行为 |
| --- | --- |
| 固定八个步骤演示替代使用流程 | 自由会话与可编辑设置，按需模拟 Agent 事件 |
| 最近多个目标持续群发、任务负责人回退 | 历史目标取首个可用者；没有负责人回退 |
| 未知 @ 阻止发送 | 未匹配文字不构成目标，继续正常回退；显式全不可用也保留提示并回退 |
| 转交先接受、所有任务强制用户验收 | 精确执行释放与责任版本检查；普通任务可由匹配身份的 Agent 完成 |
| 协助完成统一自动回唤 | 普通回复/结果不自动生成返回执行，需明确新派发 |
| 多人超时汇总、统一回唤 | 收齐发布公共汇总且不回唤；超时只记录目标状态，不自动部分汇总 |
| 持久业务暂停、固定 2:1 与全局两槽 | 当前轮取消/短期自动续跑抑制；按 position/priority/时间排序，独立目标可运行 |
| 上下文是固定六张材料卡 | 从当前运行输入关系派生，真实接受、token、费用和续接仍显示未知 |

定向 FYI 不一律静默：普通成员的显式目标可以唤醒。稀缺订阅成员的 deliveredWithoutWake 策略尚未在原型中模拟。无目标进展与知会只发表，不派发。

## 明确边界

- 0.6 新固化的来源成组调度、批次模式生命周期、A2A 失败回报、责任迁移和各承载接受证据尚未整体接入 v5；既有浏览器检查不能证明这些规则已实现。

- 不调用模型、CLI 或 API，不执行登录，不读取密钥，不写真实产物。账号“演示连接”不能视为真实认证。任意正文不会被理解为自动任务编排；模拟执行必须由评审者注入结果。
- 文件上传只登记名称、类型和大小，不读取正文、不进行图片理解；产物是文本占位，不能下载真实交付包。目录路径仅为配置元数据。
- 普通 @ 解析覆盖当前成员别名与 @all/@全体/@thread/@本帖。尚不模拟所有品种组、#ideate、concierge 或 thread policy。串行接力按钮构造一个行首目标事件，不提供完整的任意 Agent 文本解析器；并行目标禁用文本接力与多人征询级联。
- multi_mention 聚合仅在当前页面内存。刷新/「模拟聚合进程重启」会清除组，已存消息和目标队列仍保留。完成和超时分支可交互；失败空正文的 dispatch-error、重复响应和服务端事务故障需真实内核验证。
- 停止只改变请求状态；「模拟确认退出」才提供演示 teardown 证据。这不是 OS 进程退出检测。账户、工作区和审批记录均不能证明真实权限隔离。
- 全部停止的自动续跑抑制保存在页内内存，约 60 秒后解除，可按按钮模拟到期；刷新不保留这个门闩。它是上游机制的简化观察，不完整实现所有 execution fence。
- 球权面板是独立投影事件示例，不包含完整诊断/探测调度器，也不自动改变普通任务 owner 或执行状态。
- 本地 localStorage 保存演示会话、设置、任务和队列，不等于数据库事务、鉴权或跨进程恢复。原型不用于验证生产可靠性。
- 私聊、长期记忆、全局检索、精确选段转发、完整 session 链、外部条件等待等已列入实施指导的后续阶段，未在本版原型全部实现。

v4 作为历史对照保存在 [history/v4/prototype.html](history/v4/prototype.html)，其持久暂停、2:1、统一结果返回等规则不再是当前复刻基线。v5 使用独立存储键 `collab-replica-v5`，不迁移 v4 演示数据。
